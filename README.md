# EEE-111-Inspired-Programming-Samples
A collection of independently developed programming problems and sample solutions for educational and reference purposes. Inspired by topics from UP Diliman's EEE 111 – Introduction to Programming and Computation, alongside supplementary exercises, to encourage practice, problem-solving, and independent learning.

Programming Problems and Solutions

This repository contains a collection of sample programming problems and possible solutions intended for educational and reference purposes.

The exercises are inspired by topics covered in the University of the Philippines Diliman's EEE 111 – Introduction to Programming and Computation course, along with other supplementary programming exercises.

Purpose

The repository aims to:

Provide additional programming exercises for practice and self-study.
Demonstrate possible approaches and solutions to common programming problems.
Strengthen programming fundamentals, computational thinking, and problem-solving skills.
Serve as a supplementary learning resource for students and aspiring programmers.
